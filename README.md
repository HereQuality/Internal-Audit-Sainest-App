# Internal Audit — Auditor Mobile App

Flutter mobile app for auditors, talking to the `server/` Node/Express + Socket.io backend (the same backend used by `client/`, the web app). No backend changes are needed — this app is a pure frontend.

## Features

- Sign in / forgot password (email → OTP → reset)
- Post-login role picker (Auditor / Auditee) — a local UI preference, not a real permission (see `lib/providers/app_mode_provider.dart`), that decides which restricted tab set is shown: Auditor gets Auditor Dashboard / Audits / NC Monitoring, Auditee gets Dashboard / NCs. Profile is shared and reachable from either mode's app bar; switchable anytime from Profile → Switch Role.
- Dashboard — assigned/in-progress/NC-pending/completed audit stats
- My Audits — list of audits assigned to you, with "Raise NC"
- Profile — view info, edit profile (with avatar), change password
- Settings — dark mode, dashboard clock preference
- Support — ticket list, create ticket with image attachments, live chat thread (Socket.io)
- Notifications — live unread badge + list (Socket.io)

## App icon

Generated by `flutter_launcher_icons` from `assets/icon/app_icon.png` (same source as the web app's favicon, `client/src/assets/Fevicon_hqepl.png`). To regenerate after changing the source image: `dart run flutter_launcher_icons`.

## Backend

The API base URL is hardcoded in `lib/core/constants/api_constants.dart` to the production backend, `https://audit.hqepl.com/api/v1` — no `--dart-define` or build-time override needed, just `flutter run`.
